Accessibility Statement

Last Updated: August 10, 2026

Our Commitment

Ethervox Corporation is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. We aim to conform to WCAG 2.1 Level AA.

Conformance status: Partially conformant
Partially conformant means that some parts of the content do not fully conform to the accessibility standard.

Accessibility Features

This website has been designed with the following accessibility features:

  • Semantic HTML markup for screen reader compatibility
  • Keyboard navigation support for all interactive elements
  • Sufficient color contrast ratios (WCAG AA minimum 4.5:1)
  • Text that can be resized up to 200% without loss of functionality
  • Clear and consistent navigation structure
  • Alternative text for meaningful images
  • Descriptive link text
  • Proper heading hierarchy

Known Limitations

We are aware of the following accessibility limitations and are working to address them:

  • Some third-party embedded content may not be fully accessible
  • Certain complex interactive features may have limited screen reader support
  • Some older PDF documents may not be fully accessible

Feedback and Contact

We welcome your feedback on the accessibility of ethervox.ai. Please let us know if you encounter accessibility barriers:

  • Email: accessibility@ethervox.ai
  • Response time: We aim to respond within 5 business days

Technical Specifications

The accessibility of ethervox.ai relies on the following technologies:

  • HTML5
  • WAI-ARIA
  • CSS3
  • JavaScript (with graceful degradation)

Assessment Approach

Ethervox Corporation assessed the accessibility of ethervox.ai through:

  • Self-evaluation using automated testing tools
  • Manual testing with keyboard navigation
  • Screen reader testing (NVDA, JAWS, VoiceOver)
  • Color contrast analysis

Formal Complaints

If you are not satisfied with our response to your accessibility feedback, you may:

  • Contact our legal department at legal@ethervox.ai
  • In the EU: Contact your national data protection authority
  • In the USA: File a complaint with the Department of Justice

Compatibility with Browsers and Assistive Technology

This website is designed to be compatible with the following assistive technologies:

  • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
  • Screen magnification software
  • Speech recognition software
  • Keyboard-only navigation

Supported browsers: Chrome, Firefox, Safari, Edge (latest two versions)

Standards and Guidelines

We reference the following standards in our accessibility efforts:

  • WCAG 2.1 Level AA
  • Section 508 (USA)
  • EN 301 549 (EU)

Continuous Improvement

We are committed to ongoing accessibility improvements. Our accessibility statement is reviewed and updated regularly as we implement improvements and receive feedback.
